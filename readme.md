# Project Name
Image Watermark Desktop App ; Mark-IT.


## Overview
A Watermark adding desktop app to add a watermark to a local image as '©watermark'.

## Features
- Upload a file with extension *png ; *jpg/Jpeg.
- Add watermark of a colour white on top left corner.
- Save the watermark image in the directory.

## Technologies Used
- Python
- Tkinter
- Pillow
